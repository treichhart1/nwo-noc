=== Northwest Ohio Broadband Customer Signup ===
Requires at least: 6.5
Requires PHP: 8.1
Stable tag: 129.0.0
License: GPL-2.0-or-later

Shortcode [nwo_customer_signup] and dynamic Gutenberg block embed the existing dedicated HTTPS signup application. No applicant data or NOC secrets are stored in WordPress. Disabled until an administrator approves public origin/DNS. TLS and DNS-pinned read-only diagnostics, bounded timeouts, no redirects, no private-destination fallback. Deactivation preserves configuration; uninstall removes only this plugin's options and preserves pages/applications. No live deployment or message authorization.
